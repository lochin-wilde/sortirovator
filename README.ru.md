# Музыкальный сортир

*[English version](README.md) — основная, это перевод.*

Разбирает фонотеку диджея прямо в браузере: чистит имена файлов, определяет
темп и тональность, раскладывает треки по жанрам, выравнивает громкость и
отдаёт ZIP, где треки подписаны тегами, разложены по папкам и собраны в
плейлисты, которые Rekordbox открывает напрямую.

**Аудио не покидает браузер.** Раскодирование, анализ и сборка архива идут на
том компьютере, где открыта страница. Наружу уходит только текст — артист и
название, — чтобы спросить у Discogs, MusicBrainz и Last.fm, какой это жанр.
Исходные файлы на диске не меняются.

Работает на [sortirovator.pages.dev](https://sortirovator.pages.dev): открытая
страница рассказывает, что это, а само приложение пока за кодом приглашения —
идёт закрытое тестирование.

## Что умеет

| | |
|---|---|
| **Жанр** | 6712 тегов из трёх сервисов сведены к 53 категориям, которые диджей реально держит раздельно — Afro House и Tech House не попадут в одну папку. Догадка, сделанная по артисту, а не по треку, помечена `?` |
| **Темп** | сверено с Rekordbox: 93.4% в пределах ±1 BPM на 4459 треках. Плавающий темп показан как `121~`, а не одним числом, которое было бы неправдой |
| **Тональность** | в нотации Camelot: 65.0% точно и 80.8% сводимо на 4523 треках. Неуверенный ответ показан как `8A?` |
| **Громкость** | ITU-R BS.1770, интегральная или кратковременная, с учётом истинного пика, лимитер по желанию, на выходе WAV или MP3. Без лимитера усиление останавливается раньше, чем пики перейдут −1 dBTP, вместо того чтобы клиппировать |
| **Имена** | убирает то, что дописали сайты-качалки, возвращает кириллицу из транслита, берёт артиста и название из тегов файла раньше, чем гадать по имени |
| **Теги** | жанр, темп и тональность записываются в MP3 и WAV как ID3v2.4, а кадры, что в файле уже были, переносятся — обложки, биты Serato и прочее |
| **Плейлисты** | `.m3u8` по жанрам, по темпу, по кругу Camelot и по громкости, пути относительные |

Все цифры выше измерены на размеченной вручную фонотеке, а не прикинуты. Как
мерили и где результат слабый — в [web/README.md](web/README.md) (на
английском). Коротко: трудное место — жанр, 20.5% точно, остальное делится
между родственным жанром, ошибкой и честным «не знаю».

## Как устроено

Ни сборки, ни фреймворков. Приложение — статические файлы, которые работают
такими, как написаны, поэтому выкладка сводится к копированию. Номер версии
поднимается вручную в `web/js/app.js` и во всех `?v=` в HTML; что ломается,
если этого не сделать, описано в [web/README.md](web/README.md).

```
web/                  приложение, раздаётся как статика
  index.html          само приложение
  landing.html        открытая страница — самодостаточная, потому что на любой
                      другой адрес гейт отвечает страницей входа
  admin.html          разбор правок жанров (только для роли admin)
  css/styles.css      токены оформления и стили; им следуют все страницы
  js/app.js           конвейер пачки, таблица, ZIP, плейлисты, запись тегов
  js/identify.js      разбор имён, транслитерация, запросы, выбор жанра
  js/dsp.js           БПФ, темп по темпограмме, тональность по CQT-хроме
  js/loudness.js      BS.1770, истинный пик, лимитер, ресемплер, WAV и MP3
  js/tags.js          чтение и запись тегов ID3v2, Vorbis и MP4
  js/worker.js        выполняет работу со звуком вне главного потока
  js/feedback.js      очередь правок жанров
  js/admin.js         админка
  js/i18n.js          строки на русском и английском
  data/genres_map.json   генерируется — см. ниже
  og.png              карточка ссылки — генерируется
  _headers            CSP и правила кеширования
functions/            функции Cloudflare Pages
  _middleware.js      гейт, открытая страница, robots.txt
  api/feedback.js     принимает правки жанров в D1
  api/whoami.js       кому принадлежит сессия
  api/admin/feedback.js  правки на разбор
db/schema.sql         единственная таблица, в которую пишут функции
tools/
  test_all.sh         запускает все тесты
  test/               сами тесты
  measure/            замеры точности против Rekordbox
  groundtruth/        сборка эталона из Rekordbox
  build/              словарь жанров, карточка ссылки, коды приглашений
```

## Запуск локально

```bash
cd web && python3 -m http.server 8777
```

Затем откройте `http://127.0.0.1:8777/`. Открыть `index.html` как `file://` не
получится: Web Workers и `fetch` требуют настоящего источника. Локально гейта
нет — это `functions/_middleware.js`, он работает только на Cloudflare Pages.

## Тесты

```bash
sh tools/test_all.sh
```

Запускает всё из `tools/test/`. Ни сеть, ни база, ни браузер не нужны, весь
набор проходит за несколько секунд. Покрыты гейт и его открытые адреса, правки
жанров, плейлисты, запись тегов, чистка имён, транслитерация, пути в архиве,
единство оформления всех страниц и то, что словарь жанров в точности совпадает
с результатом своего генератора.

## Замеры точности

Эталон — собственная фонотека владельца в Rekordbox: темп и тональность из её
базы, жанр — из папок, по которым треки разложены вручную. Диск с фонотекой
должен быть подключён.

```bash
python3 tools/groundtruth/rekordbox_anlz.py         # бит-гриды из файлов анализа
.venv/bin/python tools/groundtruth/rekordbox_db.py  # тональность и показываемый темп; нужен pyrekordbox
python3 tools/groundtruth/match_tracks.py           # сопоставляет с файлами на диске

node tools/measure/measure_bpm.mjs                  # ~10 мин
node tools/measure/measure_key.mjs                  # ~10 мин
LASTFM_KEY=… node tools/measure/measure_genre.mjs --per-folder 25   # ~40 мин, упирается в сеть
```

База читается с копии, оригинал не открывается. Результаты ложатся в
`ground-truth/`, который не коммитится: это описание личной фонотеки.

Смотрите цифры по папкам, а не только в среднем. Среднее движется вместе с
составом библиотеки: около двух тысяч добавленных треков, в основном хаус и liquid drum & bass, подняли точность
тональности с 59.4% до 65.0%, хотя детектор при этом не менялся вовсе.

## Выкладка

Cloudflare Pages, каталог `web`, команда сборки не нужна. Обязательны две
зашифрованные переменные окружения, `SESSION_SECRET` и `INVITE_CODES`, и
привязка D1 с именем `DB`. Без секретов гейт отвечает 503, а не отдаёт
приложение без защиты. Подробности, включая отзыв доступа у одного тестера, —
в шапке [functions/\_middleware.js](functions/_middleware.js).

## Пересборка словаря жанров

`web/data/genres_map.json` генерируется и руками не правится — тест упадёт,
если файл разойдётся со свежей сборкой:

```bash
python3 tools/build/build_genres.py tools/build/genres_map.source.json web/data/genres_map.json
```

Исходник — универсальный список тегов, где большинство указывает на Pop и почти
ничего на поджанры хауса, по которым сортирует диджей. Скрипт переписывает
значения по правилам, чтобы категории повторяли полки диджея.
