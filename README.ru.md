# Музыкальный сортир

*[English version](README.md) — основная. Этот перевод для удобства.*

Раскладывает диджейскую фонотеку по жанрам прямо в браузере: определяет BPM и
тональность в системе Camelot, выравнивает громкость и отдаёт ZIP, где всё
разложено по папкам с названиями жанров.

**Ничего не нужно устанавливать, и музыка никуда не загружается.** Раскодирование,
анализ и сжатие идут на том компьютере, где открыта страница. Наружу уходят
только исполнитель и название — и только затем, чтобы спросить у MusicBrainz,
Discogs или Last.fm, что это за трек.

Сейчас в закрытом тестировании: [sortirovator.pages.dev](https://sortirovator.pages.dev)
встречает формой для кода приглашения.

## Что умеет

| | |
|---|---|
| **Раскладка по жанрам** | около 6700 тегов из трёх сервисов, сведённых к тем категориям, которые диджей реально держит отдельными полками — Afro House и Tech House не попадут в одну папку |
| **BPM** | 96% попаданий в пределах ±2 BPM на 878 размеченных треках; постоянный и плавающий темп подаются по-разному, потому что одно число для живой группы — выдумка |
| **Тональность** | в системе Camelot, 82% попаданий в гармонически совместимую |
| **Громкость** | ITU-R BS.1770, интегральная или кратковременная, ограничение по истинному пику, на выходе WAV или MP3 |
| **Имена файлов** | по желанию — приведение к виду «Исполнитель — Название» через MusicBrainz |

Все числа выше получены замерами, а не на глаз. Сами замеры, включая те места,
где результат слабый, — в [web/README.md](web/README.md) (на английском).

## Как устроено

Ни сборки, ни фреймворков. Приложение — статические файлы, которые работают
такими, как написаны. Поэтому выкладка сводится к копированию файлов, а номер
версии поднимается вручную; что ломается, если этого не сделать, описано в
[web/README.md](web/README.md).

```
web/              приложение — раздаётся любым статическим хостингом
  js/dsp.js       БПФ, BPM по темпограмме, тональность по CQT-хроме, центроиды жанров
  js/loudness.js  громкость по BS.1770, истинный пик, лимитер, ресемплер, кодеки
  js/identify.js  разбор имени файла, транслитерация, нечёткое сравнение, поиск в базах
  js/worker.js    выполняет всё перечисленное вне главного потока
  _headers        CSP и правила кеширования
functions/        функции Cloudflare Pages: замок доступа и приём исправлений
db/schema.sql     единственная таблица, в которую эти функции пишут
tools/            сборка карты жанров и наборы тестов
```

## Запуск локально

```bash
cd web && python3 -m http.server 8777
```

Дальше откройте `http://127.0.0.1:8777/`. Открыть `index.html` как `file://` не
получится: Web Workers и `fetch` требуют настоящего источника.

Локально замка нет. Замок — это `functions/_middleware.js`, он выполняется
только при выкладке на Cloudflare Pages.

## Тесты

```bash
node tools/test_gate.mjs functions/_middleware.js
node tools/test_feedback.mjs
```

Контроль доступа и приём исправлений. Оба набора работают без сети, без базы и
без браузера.

## Выкладка

Cloudflare Pages, каталог сборки `web`, команда сборки не нужна. Обязательны две
зашифрованные переменные окружения и одна привязка D1: без них замок отвечает
503, а не отдаёт приложение без защиты. Подробности, включая отзыв доступа у
одного тестировщика, — в шапке файла
[functions/\_middleware.js](functions/_middleware.js).

## Пересборка карты жанров

`web/data/genres_map.json` не правится руками, а генерируется:

```bash
python3 tools/build_genres.py tools/genres_map.source.json web/data/genres_map.json
```

Исходник — универсальный словарь, в котором 2932 тега из 6700 указывают на Pop и
только 128 на House. Для диджея это вывернуто наизнанку, и скрипт переписывает
значения по правилам.
